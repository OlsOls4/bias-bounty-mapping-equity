# Bias Bounty: Mapping Equity — OlsOls4

Code, tables and figures behind our Zindi Bias Bounty "Mapping Equity" writeups.

- `bias_discovery.pdf` — Bias Discovery report
- `documentation.pdf` — Documentation report
- `run_all.sh` — rebuilds every table, figure and cited number from scratch (`get_data.sh` fetches the public challenge data from source.coop; `DATA_SHA256SUMS.txt` verifies inputs; `requirements.txt` pins versions)
- `tables/report_numbers.csv` — every number cited in the reports, generated by script
- `v5_method.py` — regenerates our leaderboard submission exactly

The scored submission uses only challenge-provided data. No removed reference layers (TIGER roads, Microsoft buildings, USGS/HIFLD facilities, CBP) or copies of them are used anywhere.
